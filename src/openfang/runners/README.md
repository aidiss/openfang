# Runners

Different ways to run the OpenFang agent.

| Runner | Command | Description |
|--------|---------|-------------|
| CLI | `openfang chat` | Interactive terminal chat |
| Gateway | `openfang gateway` | HTTP server with web UI |
| Telegram | `openfang telegram` | Telegram bot listener |
| Cron | `openfang cron` | Scheduled job executor |

Entry point: `cli.py` (Click-based CLI)
